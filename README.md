# AI Grid tenant

GitOps for an AI Grid on ACM: a hub, its sites, and the models they serve.

This repository is also a component library: a deployment repository can pin it at one commit, select components and
set their inputs. To install that way, create your deployment repository from the template
[`ai-grid-cloud/ai-grid-deployment-template`](https://github.com/ai-grid-cloud/ai-grid-deployment-template) with **Use
this template**, and follow its
[install guide](https://github.com/ai-grid-cloud/ai-grid-deployment-template/blob/main/docs/install/README.md). The
[component reference](docs/install/README.md) stays here, versioned with the components.

To run a fork of this repository as its own hub instead, start with the [getting started guide](docs/acm/README.md).
